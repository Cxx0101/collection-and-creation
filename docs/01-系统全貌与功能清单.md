# 01 · 系统全貌与功能清单

原系统 **Viral Studio（AI 内容采集与创作）** 定位为“热点素材采集 → AI 分析拆解 → 商品图/视频/文章/POD 批量创作 → 自动化编排计划 → 资产复用”的一体化内容生产工作台。

---

## 一、前端页面体系（8 大工作台页面 + 登录页）

前端路由与导航定义位于 `apps/web/src/App.tsx`：

| 页面 | 路由 | 对应组件 | 核心职责 |
| --- | --- | --- | --- |
| **登录页** | 鉴权拦截态 | `pages/LoginPage.tsx` | 插件中心账号密码登录、浏览器跳转快捷登录（`/api/auth/browser-login`），校验会员有效期与设备配额 |
| **首页看板** | `/` | `pages/DashboardPage.tsx` | 展示采集素材数、产品数、已完成创作数、进行中任务数；近 7 天采集趋势（`Asia/Shanghai`）、任务状态分布、任务动态与 `waiting_for_user` 人工介入提醒 |
| **采集中心** | `/analysis` | `pages/AnalysisPage.tsx` | 多平台市场采集任务提交（抖音 / 小红书 / TikTok）、插件中心采集积分查询、关键词提取（从产品或资产提炼）与关键词库管理、按批次/平台/日期/关键词筛选、热度排序与服务端分页 |

## 二、核心业务功能拆解

### 2.1 多平台热点采集与关键词体系
- **采集来源**：现行统一走**插件中心市场采集**（`apps/api/app/adapters/platforms/market_collection.py`），通过 `/api/platforms/{platform}/collection-jobs` 与 `/api/platforms/{platform}/collection-job-batches` 提交单条或批量采集任务，并查询积分钱包（`/api/platforms/collection-credits`）。
- **平台与条件差异**（`apps/api/app/api/routes/platforms.py`）：
  - 支持平台：`douyin`、`xiaohongshu`、`tiktok`；支持采集类型 `video` / `image` 及单次 `limit`（1–500）、最长视频时长限制。
  - 发布时间过滤差异：抖音暂不支持时间范围（仅 `0` 不限）；小红书仅支持 `0 / 1 / 7 / 180` 天；TikTok 图文仅支持 `0` 不限。
- **关键词库与 AI 提炼**（`/api/collection-keywords*`）：
  - 支持手动录入、去重与删除，也支持提交 `keyword_extract` 异步任务，从既有产品或资产中提炼平台搜索关键词。
- **热度评分模型**（`apps/api/app/domain/viral_score.py`）：
  - 基于互动指标对数加权求和：$1.0 \cdot \ln(1+\text{likes}) + 2.0 \cdot \ln(1+\text{comments}) + 2.5 \cdot \ln(1+\text{saves}) + 2.0 \cdot \ln(1+\text{shares})$，再通过饱和函数映射为 0–100 分，权重可在设置页自定义。

### 2.2 创作中心（内容创作 + POD 素材 + AI 修图）
后端在 `apps/api/app/core/image_tools.py` 定义了 13 种图像技能（`SKILLS`），前端 `apps/web/src/creationKinds.ts` 将 4 种内容创作与图像工具组合为可搜索、可分类的工具矩阵：

1. **基础内容创作（4 类）**
   - **图片生成（`image`）**：提示词 + 多参考图生图，支持自定义分辨率/比例与批量数量。
   - **视频生成（`video`）**：支持「全能参考（`omni_reference`）」与「首尾帧（`first_last_frame`）」模式，可引用图片/视频资产及 `@技能`（`CreationSkill`，`.md` 规范文件，最大 100 KB）。
   - **产品图生视频（`product`）**：`routes/product_storyboards.py` 实现——上传产品图后生成固定 15 秒（每镜 1–3 秒，含场景切换与细节镜头）的可编辑分镜脚本，支持单镜分镜图生成或直接直出视频，遇图片不可读或品类冲突时触发人工确认问题。
   - **公众号文章（`article`）**：支持解析上传文档（`/api/creation/article-documents/parse`），结合主题和产品图完成写作、配图、HTML 排版渲染（内置 `wechat-article-layout` 技能，支持 `fresh` 等多种风格），并支持关联多个微信公众号草稿/发布同步（`routes/article_publishing.py`）。
2. **POD 电商素材工具（6 类）**
   - `image_variation`（相似图裂变）、`scene_variation`（场景裂变，最多 4 场景）、`pose_variation`（姿势裂变，最多 4 姿势）、`print_extract`（印花提取，支持白底/透明底并附 AI 整理稿免责注记）、`virtual_try_on`（AI 穿衣，需人物+服装双图）、`apparel_set`（服装套图，基于正面/背面/模特参考生成 6–9 张主图/版型/细节/平铺图）。
3. **AI 修图工具（7 类定义，其中 3 类展示于核心入口卡片，另有 4 类为图像工具能力）**
   - 核心卡片展示：`product_retouch`（商品精修）、`image_inpaint`（画笔涂抹局部重绘，配套 `InpaintCanvas.tsx`）、`image_erase`（涂抹局部消除）。
   - 后端与 `ImageToolPanel.tsx` 同时实现的工具：`image_crop`（本地比例裁剪，不调模型）、`background_remove`（输出主体蒙版扣图）、`image_upscale`（高清放大）、`image_outpaint`（智能扩图）。
   - 注：图片工具支持在提交前通过 `/api/creation/output-directory-dialog` 选择本机输出目录自动落盘导出（`image_tool_output.py`）。

### 2.3 爆款复刻工作台（视频复刻 + 图文复刻）
- **视频复刻（`/clone`）**（`routes/clone_workflow.py` + `services/clone_*.py`）：
  - **分析 + 脚本流水线**：上传或选择采集原视频 → Playwright / `yt-dlp` / 提取脚本下载原视频并 `FFprobe` 探测 → 关键帧抽帧与音频/字幕分析 → 视觉/理解模型拆解镜头与分镜脚本（存储 `CloneDraft` 并支持编辑）。
  - **多样化生成路径**：
    - 脚本 + 目标产品图 → 调用视频模型生成成片（Seedance 2.5 最长 30s，Seedance 2.0/H3 最长 15s）；
    - 支持分镜九宫格生图审批流（`storyboard-image-jobs` + `/approve`）；
    - 支持直接参考原视频生成（`direct-generate-jobs`）；
    - 支持可选的本地 **Codex 导演** 桥接（`/api/clone/codex-account*` + `codex-director.mjs`）辅助结构化导演脚本输出。
- **图文复刻（`/clone?mode=photo`）**（`routes/photo_clone.py`）：
  - 拉取采集图文原笔记图片，绑定目标产品图片后，异步生成适配的图文重绘图片与目标平台文案，支持单独重试文案生成（`/retry-caption`）。

### 2.4 可视化工作流计划（`/plans`）
基于 `CATALOG_REVISION = "workflow-v8-product-film"`（`apps/api/app/domain/workflow_graph.py`），内置有界类型检查的 DAG 编译器与运行引擎：
- **20 种现行节点类型（`NODE_TYPES`）**：
  - 触发：`trigger`（计划触发）
  - 素材读取/提炼：`collect`（市场采集）、`product_keywords`、`asset_keywords`、`read_keywords`、`read_sources`、`read_assets`
  - 编排与控制：`filter`（筛选与去重）、`foreach`（逐条循环，最多嵌套 2 层）、`condition`（条件分支）、`aggregate`（汇合结果）
  - AI 创作：`analyze_video`、`clone_video`、`clone_photo`、`generate_image`、`generate_video`、`product_storyboard`、`product_video`、`generate_article`
  - 结果：`archive`（归档与汇总）
- **完整生命周期能力**：
  - 支持 AI 对话生成工作流草稿（`/api/workflow-draft-jobs`）；
  - 计划支持版本化（`workflows` / `workflow_versions`）、执行前预检（`/preflight`）、预算预留（`workflow_budget_reservations`）、幂等防重入账本（`workflow_item_ledger`：防止同一采集素材+产品在周期计划中重复生产）以及人工确认授权哈希（`authorization_hash`）；
  - 调度模式：立即运行、单次定时、每日、每周（`workflow-schedules/preview`）。

## 三、模型与外部服务能力矩阵

| 能力域 | 供应商 / 渠道 | 配置文件 / 存储模块 | 说明 |
| --- | --- | --- | --- |
| **视觉 / 对话理解** | `ark`（火山方舟）、`deepseek`、`glm`（智谱）、`custom`（OpenAI 兼容接口） | `vision-settings.json` / `ark-settings.json` | 支撑视频分析、关键词提炼、分镜编剧、文章写作，通过 `understanding-settings.json` 指定全局默认 |
| **图片生成 / 编辑** | `ark`（Seedream）、`openai`（GPT Image）、`google`（Nano Banana）、`midjourney`（第三方兼容 API） | `ark-settings.json` / `generation-settings.json` | 通过 `image-default-settings.json` 指定全局默认；各模型能力与参考图上限由能力目录统一描述 |
| **视频生成** | `ark`（Seedance 2.5 / 2.0）、`minimax`（H3 V2）、`kling`（可灵 Access+Secret JWT）、`qwen`（通义万相 Wan）、`comfyui`（本机 H3） | `ark-settings.json` / `generation-settings.json` | `comfyui` 仅在 `app_env != "desktop"` 且本地服务就绪时暴露，网页版需评估移除或网关化 |
| **平台采集与鉴权** | 插件中心（`plugin-market.fqwlkj.cn` 或本机调试端点） | `.env` + `plugin-center-device-id` | 负责账号登录态、订阅期检查、设备数限制、采集积分扣减与按页采集代理 |
| **媒体云存储** | 阿里云 OSS（`oss2`）、火山引擎 TOS（`tos`）、本地磁盘 | `storage-settings.json` + `storage-index.sqlite3` | 本地写入为主，后台异步循环同步/删除远端对象，提供连接测试与同步统计 |
| **公众号发布** | 微信公众号官方 API（`adapters/platforms/wechat.py`） | `wechat-settings.json` + `wechat-accounts.json` | 支持多公众号凭证配置与草稿/发布状态同步，不使用浏览器模拟点击 |

## 四、现行可用 vs 已退役 / 桌面限定边界

在分析原库代码时，以下边界需要在重构为网页项目时明确区分：

1. **已明确退役但数据库/路由仍保留兼容的历史模块**
   - **旧版多平台浏览器自动发布**：`RETIRED_PUBLISHING_JOB_TYPES` 包含 5 个任务类型（`publication_copy`、`publish`、`publish_fill`、`publish_account_check`、`publish_verify`），`RETIRED_NODE_TYPES` 包含 4 个工作流发布节点（`publication_copy`、`publish_targets`、`publish_article_targets`、`verify_publication`）。当前代码已无对应发布页面或浏览器发布 Worker，旧发布任务进入执行前会被安全取消。
   - **旧版浏览器采集兼容端点**：`POST /api/platforms/{platform}/session-jobs` 已被标记为 `deprecated=True` 并直接返回 HTTP `410`（“浏览器采集已停用，请使用插件市场采集”）。
2. **仅桌面端 / 单机操作系统强依赖功能**
   - **本地文件夹弹窗与自动导出**：`POST /api/creation/output-directory-dialog` 调用 Windows `powershell.exe` 弹出 `FolderBrowserDialog`，且仅支持 `win32`。
   - **桌面在线更新**：`/api/desktop-updates/*` 及设置页「软件更新」标签依赖请求头 `X-Workflow-Desktop-Control` 与 Electron 主进程协同。
   - **桌面托盘与休眠控制**：`/api/internal/workflow-runtime/lifecycle` 与 `/notifications` 供 `apps/desktop/workflow-runtime.cjs` 驱动托盘保活与系统休眠通知。
   - **本地 Codex CLI 导演**：`/api/clone/codex-account*` 通过 `node` 拉起 `apps/desktop/codex-director.mjs` 调用本机 `@openai/codex` 二进制及本机目录授权。
