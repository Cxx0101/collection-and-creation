# 06 · C 端平台型原型与界面设计规范

为摆脱原桌面项目偏重内部表单工具的页面形态，新项目前端界面基于 `ui-ux-pro-max` 设计系统重新规划为**面向 C 端内容创作者的现代平台型产品**，并提供离线可直接浏览器打开交互的高保真原型。

---

## 一、原型与设计资产文件

- **前后端原型彻底分离**：
  - **原型导航页**：[`prototype/index.html`](../prototype/index.html)（快速进入前台或后台原型）；
  - **C 端用户平台原型**：[`prototype/web/index.html`](../prototype/web/index.html)（纯 C 端视角，不含任何管理后台入口，包含完整创作/复刻/采集/商品与技能 CRUD/个人多模型与公众号绑定/支付宝微信收银台支付页）；
  - **统一管理后台原型**：[`prototype/admin/index.html`](../prototype/admin/index.html)（独立后台，包含全站概览、用户与短信策略 CRUD、积分套餐 CRUD、支付宝/微信通道配置、多实例大模型供应商接入与定价 CRUD、TikHub 与 OSS/TOS/COS 配置、全站任务监控）。
- **设计系统主规范**：[`design-system/viralstudio-c-platform/MASTER.md`](../design-system/viralstudio-c-platform/MASTER.md)（包含色板、字体、圆角、阴影、间距与组件令牌）及 `pages/` 子页面覆盖规则。

## 二、C 端平台化重构的核心 UX 转变

| 维度 | 原项目界面（已弃用） | 新 C 端平台型界面 |
| --- | --- | --- |
| **首屏入口** | 统计看板表格与数字指标卡 | **灵感广场（Discover Plaza）**：顶部全站提示词/爆款链接一键输入框 + Bento 四大核心能力卡 + 瀑布流爆款模板画廊 |
| **导航结构** | 8 项纯文本宽侧边栏混合设置 | **顶部全局吸顶搜索与状态栏（64px）+ 左侧极简图标导轨（76px，6 个核心域）+ 移动端底部 Tab（≤5 项）** |
| **创作中心** | 长页面平铺表单与历史列表 | **三栏 Split Studio 工坊**：左侧 13 项分类目录 + 中间浅色工作台（基础创作保留参考图/提示词/分镜/公众号预览；POD 电商素材与 AI 商业修图展示「上传原图 → 生成结果」创作前后对比卡与「一键做同款」，涂抹重绘/消除保留交互画布，均不展示输出图片列表）+ 右侧双轨模型、参考图上传、提示词与动态能力参数面板；产物统一归档至个人资产库 |

| **资产与计划** | 散落多页且依赖本地目录弹窗 | **个人空间完整 CRUD（资产 / 商品 / 自动化流水线）**：支持产品多图增删改、工作流新建编辑启停、资产上传删除批量 ZIP 与再创作 |

## 三、视觉令牌与无障碍强制规范（来自 `ui-ux-pro-max`）

1. **色彩系统（高对比中性画布 + 创意品红主交互色）**：
   - 页面画布 `--color-background: #FAFAFA`、卡片 `--color-card: #FFFFFF`、主键 `--color-primary: #18181B`、强调按钮 `--color-accent: #DB2777`（保证白色文字对比度 ≥ 4.5:1）、主文本 `--color-foreground: #09090B`、次文本 `--color-muted-foreground: #52525B`。
- 创作工坊中心工作台统一采用与两侧面板一致的浅色高对比画布（`#FFFFFF` 主画布、`#FAFAFA` 卡片与 `#E4E4E7` 边框），保持 C 端全站清爽通透。
2. **字体与数字排版**：
   - 字体族采用 `Inter + Noto Sans SC`；所有积分余额、热度分、消耗明细强制启用 `font-variant-numeric: tabular-nums` 防止数字跳动。
3. **无障碍与交互底线（交付前必检）**：
   - **零 Emoji 图标**：全站图标统一使用 `@phosphor-icons/react`（或等价线性 SVG），装饰图标带 `aria-hidden="true"`，纯图标按钮必须配置 `aria-label`。
   - **触控与焦点**：桌面/移动端可点击控件不小于 `40–44px`，所有交互元素保留 `:focus-visible` 清晰键盘焦点框，并支持 `prefers-reduced-motion` 关闭非必要动效。
   - **AI 生成透明提示**：所有由大模型生成的图片、视频与文章卡片均带有明确 AI 属性标签，并结合实时任务抽屉避免长时间无响应白屏转圈。
